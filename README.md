# Rice Mill Analytics: Business Analyst Portfolio

Business analysis and Power BI dashboard for a rice mill (individual project, IS 3920).
All data is synthetic. The dashboard answers the owner's questions on buying, milling, selling and credit.

## Structure
- `docs/`: business analysis, process models, requirements, data model, research
- `data/raw/`: 13 synthetic CSV files (see `data/README.md`)
- `scripts/generate_dummy_data.py`: regenerates the data (`python scripts/generate_dummy_data.py`)
- `powerbi/`: `rice_mill_dashboard.pbix`
- `assets/screenshots/`: dashboard screenshots
